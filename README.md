# tobilicous.github.io

This repository exists only to redirect the old GitHub Pages URL to the current site:

**<https://oluwatobilobaadesanya.com>**

`index.html` and `404.html` are identical instant `meta refresh` redirects with a `<link rel="canonical">`,
which Google treats as a permanent redirect. `404.html` covers old deep links, so any previously indexed
path redirects rather than dead-ending.

The original site's source is archived privately in `personal-site-legacy` and in `portfolio-v2/legacy/`.
